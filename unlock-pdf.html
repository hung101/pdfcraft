Frequently Asked Questions

Is it safe to unlock confidential PDFs here?
Yes, absolutely. Because PDFCraft processes all tasks locally on your device, your PDF passwords and document contents never leave your browser, making it safer than traditional server-side tools.
Do I need the original password to unlock a PDF?
If the file asks for a password when you open it, yes: you must know and enter it. PDFCraft uses it to unlock the document locally and generate a restriction-free copy. If the file opens without a password and is only locked against printing or editing, no password is needed.
Are there file size limits for unlocking?
You can process large PDF documents directly in your browser. There is no fixed cap — the practical ceiling is your device’s available memory, and speed depends on your CPU.
Does unlocking work offline?
Yes. After your first visit, the Unlock PDF tool works without an internet connection.

This decrypts a document you can already open

Unlocking takes the password you supply, uses it to decrypt the document, and writes out an equivalent PDF with the encryption removed. It is the exact inverse of protecting a file, and it is useful when a document you legitimately hold keeps prompting you every time you open it, or when a tool in your workflow cannot handle encrypted input.

To be unambiguous about what this is not: it is not a password cracker. There is no guessing, no dictionary, and no bypass. If you do not know the password, this tool cannot open the document, and that limitation is deliberate rather than an oversight. (A file that opens without a password has none to know: Unlock only removes its permission flags.)

What to expect from the unlocked copy

  • You need the password. Without it there is no key, and without the key the content cannot be decoded.
  • The output is genuinely unencrypted. Anyone who receives it can open it, so treat the unlocked copy as a sensitive file in its own right.
  • Content is unchanged. Pages, fonts and images come through as they were; only the encryption layer is gone.
  • Very new encryption revisions may not be supported. If a document refuses to decrypt with a password you are certain is right, it is likely using a scheme this implementation does not cover.

Permissions, passwords and legitimate use

Can this remove a password I do not know?
No, and it is not designed to. Decryption requires the key that the password produces. A tool that could open arbitrary protected documents without their password would be a tool for reading other people's files.
Why would I remove a password from my own document?
Commonly because the protection has outlived its purpose — an archived statement you now need to search, or a file heading into a process that cannot accept encrypted input, such as a merge. See how to merge password-protected PDFs.
The file opens without a password but will not let me print. Can this help?
Yes. That is a permissions flag rather than an open password. A file that opens without a password can always be decrypted, so Unlock PDF removes the flags without asking for one.
