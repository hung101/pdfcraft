Frequently Asked Questions

How is this different from adding a text box over the PDF?
An overlay draws new text on top of the old, and the original stays in the file where anyone can select or extract it. This tool removes the original text-showing operator from the page's content stream and draws the replacement in its place, so the old text is not recoverable from the output.
Will the replacement match the original font?
Not exactly. Most PDFs embed only a subset of a font containing the characters the author actually used, so new characters you type are usually not available in it. The replacement is drawn in a matching standard font (Helvetica, Times or Courier), which can look slightly different. The tool tells you when this happens.
Does the rest of the line move to fit my new text?
No. Text that follows on the same line stays where it is, so a longer replacement can overlap it and a shorter one leaves a gap. Check the result before sending the file.
Why can't I edit some text on the page?
Rotated, skewed or vertical text cannot be rewritten, because replacements are drawn horizontally. Text inside a scanned image is not text at all. Password-protected files must be unlocked first, and characters outside the Western European set are not supported yet.
Are my files uploaded anywhere?
No. The PDF is read with the browser File API and rewritten in your tab. The processing code makes no network calls of any kind, and the libraries it uses are served from this site rather than a third-party CDN.

Replacing text instead of covering it

Most tools that advertise PDF text editing draw a white box over the old words and place new words on top. The original text is still in the file, still selectable, and still recoverable. This tool takes the harder route: it finds the operator in the page's content stream that drew the phrase, and rewrites that operator.

The consequence is that the replaced text is genuinely gone from the document rather than hidden behind something. The consequence of the consequence is that this is a far more constrained operation, and it is worth knowing where the constraints bite before you start.

A visible phrase is frequently drawn by several separate operators — a line that reads as one sentence to you may be four or five instructions to the PDF. And the bytes inside those instructions are often glyph indices into a font subset rather than characters, which is why you cannot always type arbitrary new text into an existing font.

Where text replacement runs out of room

  • Nothing reflows. PDF has no concept of a paragraph. Replacement text that is longer than the original does not push the following words along; it overlaps them.
  • Subset fonts contain only the characters already used. If the embedded font never needed a letter, that letter is not available, and the text falls back to a standard font that may not match.
  • Scanned pages have no text to edit. A photographed document is an image. There are no text operators to find, because none were ever written.
  • Rotated and vertically-set text is refused rather than silently mangled.
  • The source document always beats a PDF-level edit. If you have the original file, change it there and export again. This tool is for when you do not.

Editing text in a finished document

Is the old text really removed, or just hidden?
Removed. The content-stream operator that drew it is rewritten, so the original characters are not present in the saved file. That is the difference between this and an overlay editor, and you can verify it by searching the output.
Why can I not type certain characters?
Embedded fonts in a PDF are usually subsets containing only the glyphs the document actually used. A character that never appeared has no glyph to draw, so it cannot be rendered in that font.
Why did editing one phrase leave part of the old line behind?
Because that line was drawn by more than one operator. What looks like a single phrase can be several separate instructions, and each one has to be edited.
Can I edit text in a scanned PDF?
No. A scan is an image of a page, with no text objects inside it. Editing it would mean recognising the characters first and then rebuilding the page, which is a different problem entirely.
