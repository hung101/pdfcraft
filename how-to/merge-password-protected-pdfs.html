How to Merge Password-Protected PDFs, Like Bank Statements

Unlock each file, merge them, then add one password back if you need it. Nothing is uploaded.

Bank statements, payslips and tax letters often arrive as password-protected PDFs, one per month. When you need them as a single file, say twelve months of statements for a loan or visa application, the usual merge tools refuse. Some show a vague error, some ask you to upload each file with its password to their server, and some just produce a blank result.

This guide does it in three steps, all inside your browser tab: remove the password from each file with Unlock PDF, combine them with Merge PDF, and, if the result still needs protecting, add one password back with Protect PDF. Your statements and passwords never leave your device.

Why Merging Fails on a Protected File

An encrypted PDF stores its pages, fonts and text in scrambled form. To copy a page into a new document, a merge tool has to decrypt it first, and it can only do that with the key the password produces. PDFCraft's merge engine, pdf-lib, does not decrypt at all; it refuses any encrypted file. So the password has to come off before the merge, not during it.

If you add a protected file to Merge PDF anyway, PDFCraft names the file that's encrypted and tells you what to do next, rather than failing with a generic "could not read" message.

Two Kinds of Protection

PDF protection comes in two forms, and they behave differently:

What you seeWhat it isDo you need the password to unlock?
The file asks for a password before it opensAn open password (also called a user password). The content is encrypted with it.Yes. You must know it.
The file opens normally, but printing, copying or editing is blockedA permissions password (owner password) only. The file is encrypted, but with a key anyone can derive.No. Unlock PDF removes the restrictions without asking.

Bank and payroll statements almost always use an open password, often built from personal details such as your date of birth or ID number. The email or letter that came with the first statement usually explains the format.

Step by Step

  1. Unlock each file. Open Unlock PDF, add one statement, enter its password and press Unlock. Download the unlocked copy. Unlock PDF handles one file at a time, so repeat this for each statement. If every statement uses the same password, it's quick.
  2. Merge the unlocked copies. Open Merge PDF and add all the unlocked files. Drag them into the order you want, oldest month first for example, because the merged file follows the order of the list at the moment you press merge. Then download the result.
  3. Protect the merged file, if needed. The merged file has no password. If you're sending it somewhere that expects one, open Protect PDF and set a single new password for the whole file.
  4. Delete the unlocked copies. They are plain, unprotected PDFs sitting in your downloads folder. Once the merged file is done, delete them.

Why Not Use an Upload Tool?

A bank statement carries your account number, balance, address and every transaction for the month. An online tool that unlocks or merges on its server needs both the file and its password, which means handing over exactly the two things the bank's protection was meant to keep together.

PDFCraft does the decryption and the merge in the browser tab. No code path sends file contents or passwords anywhere, and after your first visit the tools work with the network off. If you want to check rather than trust that, open your browser's developer tools, switch the network off, and run the whole job. The security page explains what the site does load: Google Analytics counts visits, and that's separate from your files.

What Can Go Wrong

  • Unlock says to verify your password. The password is case-sensitive, and spaces count. Check the format your bank describes, for example whether a date is written DDMMYYYY or YYYYMMDD.
  • Unlock says the file uses an encryption scheme PDFCraft can't remove. Unlock PDF reads RC4 (revisions 2 and 3), AES-128 (revision 4) and AES-256 (revision 6). It doesn't support the short-lived AES-256 revision 5, or files protected with a digital certificate instead of a password. For those, remove the protection in desktop PDF software first.
  • Bookmarks are missing after the merge. Merging copies pages, and bookmarks live at the document level, so the merged file has none. Statements rarely have bookmarks, but the merge and split guide lists what else does and doesn't survive.
  • The tab stalls on a big batch. Everything happens in your device's memory. Statements are small, but if you're merging dozens of scanned documents, merge them in groups and then merge the groups.
About the new password: Protect PDF writes RC4 128-bit encryption, the legacy scheme every PDF reader can open. It keeps out casual viewers, but it is not strong against someone who runs a password-cracking program on the file. A long password helps; for anything highly sensitive, use desktop software that writes AES-256. The password guide covers this in detail.

Frequently Asked Questions

Can I merge protected PDFs without knowing the passwords?

Only if they open without a password and are just restricted against printing or editing. If a file asks for a password when you open it, you need that password. PDFCraft doesn't guess or crack passwords.

Will the merged file keep the original passwords?

No. The merged file is unprotected until you add a password with Protect PDF. If you do, the whole file gets one new password, not the original ones.

Are the unlocked statements changed in any way?

No. Unlocking removes the encryption and writes the same pages, text and images back out. The text stays selectable and searchable.

Does this work on a phone?

Yes. It's the same web page in a mobile browser. On iPhone, the downloaded files go to the Files app, where you can add them to Merge PDF the same way.

Does it work offline?

Yes, after your first visit. Open PDFCraft once while you're online and the tools are cached in your browser.
