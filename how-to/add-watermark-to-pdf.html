How to Watermark a PDF, and What a Watermark Actually Does

Marking drafts and confidential copies without uploading them, and the limits worth knowing first

You are about to send a draft that must not be mistaken for the final version, or a confidential copy that should make its origin obvious if it travels further than intended. A watermark is the standard answer, and for those two jobs it works well. What it does not do is protect the document, though plenty of tools let you believe otherwise. This guide covers what a watermark actually is inside a PDF, how to add one here without the file leaving your device, and how to choose between a mark that is easy to read and one that is hard to remove.

What a Watermark Is Inside the File

A PDF page is a list of drawing instructions, painted in order. Adding a watermark appends a few more to the end of each page's list: pick a font, set a transparency, position and rotate, then draw the text. Because those instructions come last, they are painted over everything already on the page. The see-through effect comes from a transparency setting on the drawing state rather than from a lighter colour, which is why the page underneath still shows.

We checked this by running the tool itself on a test file rather than describing it from memory. A two-page document came back with one text instruction added to each page, last in paint order, and the original drawing instructions left exactly as they were; the only other change was to the file's metadata, where the producer name and modification date are updated. Two consequences follow, and both tend to surprise people.

The watermark is real text. It is drawn with a font, not pasted in as a picture, so a PDF reader treats it like any other text on the page. Search the document for "DRAFT" and every page matches. Select the whole page and copy it, and the word comes along. Text-extraction tools read it out alongside your content.

It barely changes the file size. The text is set in Helvetica, one of fourteen fonts that every PDF reader has built in, so no font has to be embedded in the file. In our test the whole two-page document grew by under 700 bytes.

Three Jobs, Three Approaches

Most people reach for a watermark to do one of three things, and each wants different settings.

What you wantWhat to doThe trade-off
Stop a draft being mistaken for the final"DRAFT" at the defaults: size 50, 45 degrees, 30% opacityAnyone with a PDF editor can delete it, which does not matter for this job
Make a leaked copy traceable to its recipientOne line per recipient, such as "Prepared for J. Smith, 15 Oct 2026", run once for each copyA deterrent only: it can be deleted, or cropped out of a screenshot
Make the mark hard to strip outWatermark first, then run the file through Compress PDFEvery page becomes an image, so text stops being selectable or searchable, and a text-heavy file can get bigger

The third row needs a word of explanation. Compress PDF works by rendering every page to an image and rebuilding the document from those images (the compression guide explains why). After that, the watermark is no longer a separate instruction that can be deleted. It is pixels, mixed in with everything else on the page. That makes it far harder to remove, and it costs exactly what flattening always costs: nobody can select, search or copy the text any more, including you. Keep the unflattened original.

How to Add a Watermark Here

  1. Open Watermark PDF and drop your file in. It is read by your browser; nothing is uploaded.
  2. Type the text. It is a single line, and "DRAFT" is filled in to start.
  3. Set the size (10 to 150), the opacity (5% to 100%), the angle in degrees (0 to 360, where 0 is level and 45 is the classic diagonal) and the colour.
  4. Apply it, download the result, and open it before you send it anywhere.

The mark is centred on the visible page, including pages that have been rotated or cropped, and turns around its own centre, so it stays centred at any angle. There is no page-range option: every page gets the same mark. To watermark only part of a document, split out those pages, watermark them, and merge the pieces back in order.

Settings That Read Well

  • Opacity around 20 to 30 percent. Enough to be unmistakable, faint enough that the page underneath stays readable. Push it much past half and the watermark starts to hide the content it is labelling.
  • Grey or a muted red rather than black. Black at low opacity reads as grey anyway; a colour separates the mark from the body text more clearly.
  • Size it to the length of the text. The tool centres your text but does not shrink it to fit. A short word like DRAFT is about 170 points wide at the default size of 50, comfortably inside an A4 page, which is 595 points across. A full line is a different story: "Prepared for Jane Smith, 15 Oct 2026" measures about 840 points at size 50 and runs off the page. At 30 it is about 500 points and fits. As a rule, keep single words at 50 and full lines between 25 and 30.
  • 45 degrees for a diagonal, 0 for a level line. The angle is measured as the page is displayed, so it comes out right on pages that have been rotated, too. A level line is easier to read; a diagonal is the convention most people recognise as a watermark.

What a Watermark Will Not Do

  • It does not stop anyone copying the text. Everything underneath stays exactly as selectable as it was. The watermark adds a word to what gets copied; it takes nothing away.
  • It can be deleted. It is one instruction per page, and anyone with an editor that can remove page content can remove it in a minute.
  • It is not a tracking code. The watermark carries no hidden fingerprint: it is exactly the text you can see, which is why a per-recipient line only works if the recipient's name is actually in it.
  • A screenshot keeps it; retyping does not. A screenshot carries the watermark along with the page, which is part of its value. Someone who retypes the text, or crops the mark out of a picture, leaves it behind.
  • Western European characters only. The built-in Helvetica covers English and the main Western European languages. Letters such as Ł, č, ş and ő, and Greek, Cyrillic, Chinese, Japanese, Korean or Arabic text, stop with an error, and no file is produced.
  • Password-protected files must be unlocked first. The tool cannot open an encrypted document, so it stops before changing anything. Use Unlock PDF first: a file that opens without a password unlocks without one, and otherwise you need to know the password.
Heads up: if the real worry is that the document must not leak, a watermark is the wrong primary tool. Control who receives the file, put a password on it, and treat the watermark as the label on top. Order of Operations

When a file goes through several tools, the order matters:

  1. Edit, reorder, number and watermark first. Page numbers and watermarks are both drawn on top of the page, so either can go first.
  2. Flatten next, if you want the mark baked in. Compress PDF turns every page into an image, watermark included. Nothing after this step can change the text, so do it once everything else is final.
  3. Add a password last. The editing tools here refuse encrypted files, so encryption has to be the final step.

Checking the Result

  1. Look at the first and last pages. Confirm the mark sits fully on the page and is not clipped at the edges, especially if you typed a long line.
  2. Search for the watermark word. Every page should match. If you flattened the file, no page will, because there is no text left to search.
  3. Check that the page underneath is still readable at the size the recipient will see it, on a phone as well as a monitor.

Why Doing This Locally Matters

The documents people watermark are, almost by definition, the ones they would rather not hand to a stranger: draft contracts, internal reports, confidential copies. A watermarking service that works by upload has to receive the whole document in order to add one word to it.

Here the work happens in your browser tab. The file is read from your disk, the watermark is added in memory, and the result comes back to you as a download. Frequently Asked Questions

Can someone remove a watermark from my PDF?

Yes. A watermark added here is one drawing instruction on each page, and anyone with a PDF editor can delete it. If it needs to be hard to remove, watermark the file and then run it through Compress PDF, which flattens every page to an image. That turns removal into editing pixels, at the cost of losing selectable text.

Will the watermark show up when someone copies text from the PDF?

It can. The watermark is drawn as real text, so searches find it and text extraction reads it out alongside your content. Whether a particular copy picks it up depends on what is selected.

Can I watermark only some pages?

Not in one step: the tool applies the same mark to every page. Split out the pages you want marked, watermark that part, and merge the pieces back together in order.

Can I use a logo or image as the watermark?

Not with this tool, which adds text only. Sign & Edit can place an image on individual pages instead, as an overlay on the pages you choose.

Does a watermark make the file bigger?

Barely. The text uses a font that every PDF reader has built in, so nothing needs embedding. In our test, watermarking a two-page document added under 700 bytes.

Does this work offline?

Yes, once the page has loaded. The PDF library it uses is served from this site rather than a third-party CDN, so nothing has to be fetched while you work.
